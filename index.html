taudit package channels

taudit audits CI/CD pipeline authority for GitHub Actions, Azure Pipelines, GitLab CI and Bitbucket Pipelines. This site hosts its APT repository.

APT (Debian/Ubuntu, amd64)

sudo install -m0755 -d /etc/apt/keyrings
curl -fsSL https://0ryant.github.io/taudit/apt/taudit-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/taudit.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/taudit.gpg] https://0ryant.github.io/taudit/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/taudit.list >/dev/null
sudo apt update && sudo apt install taudit

Other channels

cargo install taudit                # any platform with Rust
choco install taudit                # Windows (pending community moderation)

Archives, checksums and the .deb for each version are attached to the GitHub releases.

Signing

The APT Release file is signed with a free, self-generated OpenPGP key so apt will accept the repository. That is repository-integrity signing, not code signing: the taudit binary is unsigned on every platform. Every archive additionally carries a SHA-256 sidecar, and the package manifests pin those hashes.
